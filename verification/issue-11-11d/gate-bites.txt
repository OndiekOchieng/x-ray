NOTE ON W1. The first run of this set recorded W1 as PASSING 18/18, which was a
defect in check 14 rather than a pass: it accepted any outline wider than a
hairline, and Chrome keeps drawing its own focus ring after the authored rule is
deleted. Measured on this machine, the browser default is `outline: auto 1px,
offset 1px` and the authored ring is `solid 2px, offset 2px`, so the check now
requires a ring at least 2px wide and offset clear of the control's border, or
a box-shadow. The corrected W1 run is recorded below, and the hardened check
immediately found a real defect in the clean tree as well — the published
version is a self-contained document that loads none of the application's
stylesheets, so its links had only the default ring.
