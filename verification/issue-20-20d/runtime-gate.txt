=== composition semantics ===
every slot AVAILABLE            -> COMPOSED; runtime registered; summary logged (names only)
any slot not AVAILABLE          -> INCOMPLETE; nothing registered; each missing slot named
                                   with its reason. getExecutionRuntime() keeps returning
                                   unconfiguredResearchRuntime, so a fresh run ends
                                   CAPABILITY_BLOCKED exactly as every #6-#11 gate expects.
no submitted URL                -> all ten stages report one capability gap each
reevaluation                    -> deliberately not implemented; startReevaluation says a
                                   re-evaluation cannot be planned rather than re-researching
                                   the original URL and calling it a successor version

=== search -> retrieve sequencing ===
search returns NOT_RETRIEVED results with no extract (20c).
gatherMaterial then fetches each discovered locator, keeping the SEARCH handle.
  obtained     -> RETRIEVED / PARTIAL with an extract; isInspectable true
  unobtainable -> kept in the material, no extract; isInspectable false
Unobtained records are kept, not dropped: a record that was found and could not be
read is a research fact, and dropping it would make the search look narrower than
it was. XR-INV-006 turns on the extent of the search.

TRACE refuses to mint evidence from a non-inspectable document, and throws rather
than dropping the proposition, because StageOutcome is a contribution OR a gap and
never both -- so a stage that kept its other work could not report the refusal.
Defence in depth: with that guard removed, STAGED validation still catches it as
XR-INV-006/EVIDENCE_FROM_UNOBTAINED_SOURCE (verified, see report).

=== pause_turn continuation ===
Implemented at the Anthropic server-tool transport boundary, as 20c recorded.
  one user message, sent once; each continuation appends the paused assistant
  message unchanged, including every encrypted_content
  blocks accumulate across turns, so earlier results are never discarded
  bound: 4 continuations (5 requests). At the bound the gathered results are
  returned with moreAvailable: true and a note saying the turn was still paused.
