strict: true
  - a TOP-LEVEL property of a tool definition, beside name/description/input_schema
  - no beta header; anthropic-version: 2023-06-01 unchanged
  - guarantees: tool `input` strictly follows `input_schema`, and tool `name` is valid
  - implemented by grammar-constrained sampling over a compiled schema
  - composes with forced selection; forced tool_choice is KEPT
  - not accepted on the computer-use / browser-use toolsets (not used here)
  - server tools (web_search, web_fetch) do NOT receive it — 20c's retrieval
    path is untouched

SUPPORTED subset
  types object, array, string, integer, number, boolean, null
  enum over scalars/null only; const; default
  anyOf, allOf (no allOf with $ref); $ref/$defs/definitions (no external $ref)
  required; additionalProperties — MUST be false for objects
  formats date-time, time, date, duration, email, hostname, uri, ipv4, ipv6, uuid
  array minItems — only 0 or 1

NOT SUPPORTED
  recursive schemas; complex types in enum; external $ref
  numeric constraints (minimum, maximum, multipleOf)
  string constraints (minLength, maxLength)
  array constraints beyond minItems 0/1
  additionalProperties anything other than false
  -> an unsupported feature is a 400
