----------------------------------------------  -----------------------  --------------------

       stop_reason: refusal                     CapabilityUnavailable    REFUSED_FOR_INPUT

  overloaded_error, timeout_error               AdapterFailure           TRANSIENT
network error / timeout                         AdapterFailure           TRANSIENT
stop_reason: max_tokens                         AdapterFailure           TRANSIENT
any other 4xx                                   AdapterFailure           PERMANENT
200 prose / wrong tool / non-JSON               AdapterFailure           PERMANENT
malformed or invalid structured answer          AdapterFailure           PERMANENT
a handle that was not offered                   AdapterFailure           PERMANENT

Signals are read in order of how much they can be trusted:
  1. HTTP status, where it decides alone            (401, 402, 403, 404, 413)
  2. the documented error.type, filtered to a closed vocabulary
  3. documented headers   (retry-after separates the two forms of 429)
  4. error.message — ONE condition only (400 spend limit), under two guards:
       the message must be <= 400 characters, and must contain no 24-character
       run that also appears in the request we sent.
