# CAL-015 — System explanation requires an observable falsifier

**Status:** Executable v0.3 calibration · Reviewer model-assisted

## Situation

A system narrative that treats every possible result as confirmation is not a reversible finding.

## Wrong move

Promote the narrower evidence or context into the broader underlying proposition.

## Expected judgment

Keep each proposition and time context distinct. If a finding exceeds the evidence, raise a blocking Reviewer finding and route it for revision. This is semantic judgment, not a deterministic source ranking.

## What evidence would change the judgment

A stated observation that would count against the explanation.
