# CAL-010 — Evidence does not inherit along a causal chain

**Status:** Executable v0.3 calibration · Reviewer model-assisted

## Situation

A well-supported first link does not establish mechanism, intent, or later effects.

## Wrong move

Promote the narrower evidence or context into the broader underlying proposition.

## Expected judgment

Keep each proposition and time context distinct. If a finding exceeds the evidence, raise a blocking Reviewer finding and route it for revision. This is semantic judgment, not a deterministic source ranking.

## What evidence would change the judgment

Independent evidence for each material causal link.

## Executable anchor

The synthetic Kenyatta/Maralal fixture and its mutations are exercised by `pnpm check:source-position-review`. This is a reasoning example, not a claim about the historical record.
